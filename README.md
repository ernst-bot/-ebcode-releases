# EBcode – Releases

Dieses Repository enthält **ausschließlich Release-Assets** von EBcode Desktop:
den Windows-Installer `EBcode_<version>_x64-setup.exe`, seine Signatur und
`latest.json` für das automatische Update.

Der Quellcode ist privat und liegt nicht hier.

Installation: Installer aus dem neuesten Release herunterladen und ausführen.
Danach aktualisiert sich EBcode selbst. Für die volle Nutzung ist eine Lizenz
erforderlich.
